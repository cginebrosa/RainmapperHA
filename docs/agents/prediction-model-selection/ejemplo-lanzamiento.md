# Ejemplo de mensaje para lanzar la investigación

Copia este mensaje en una conversación de Codex abierta en el proyecto
RainmapperHA. Puede ser una conversación nueva para mantener separado el estudio.
Guardar este ejemplo no activa el goal ni inicia experimentos.

```text
Revisa el estado de docs/agents/prediction-model-selection/ y del goal.
Si ya está activo, continúa desde sus etapas verificadas; no dupliques cálculos.
Si está completado, informa del cierre y no lo relances sin un encargo nuevo.
Sólo si todavía no se ha iniciado, lánzalo con un agente dedicado y un goal persistente.

Lee primero docs/codex-start-here.md y docs/active-context.md.
Después sigue README.md, goal.md, metodo.md, plan-de-trabajo.md
y estado.md de esa carpeta.

Autorizo preparar los scripts y ejecutar los experimentos locales
dentro de los límites documentados. Completa el inventario y cierra
el protocolo antes de calcular. Continúa hasta entregar el informe
con evidencias y limitaciones.

Conserva el estudio anterior, los datos y modelos activos.
No modifiques HA real, el worker ni su coordinador.
Informa brevemente del progreso aproximadamente cada minuto.
```

El alcance y los límites están en [goal.md](goal.md); el avance efectivo se
registra en [estado.md](estado.md).
