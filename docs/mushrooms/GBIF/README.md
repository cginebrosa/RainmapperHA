# Accesos antiguos al visor GBIF

La aplicación completa está en [local-apps/gbif](../../../local-apps/gbif/README.md):

- Código: `local-apps/gbif/code/`.
- Datos y fotografías: `local-apps/gbif/data/`.
- Guía e informes: `local-apps/gbif/docs/`.

Aquí solo quedan dos enlaces simbólicos a los snapshots, sin copias de sus datos.
Se conservan para que los marcadores y las revisiones guardadas por el navegador
bajo la URL de archivo antigua sigan siendo accesibles.
