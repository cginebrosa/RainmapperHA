Map help

Rain periods

Use the bottom buttons to switch the accumulated rain period. The current period changes immediately and does not overwrite your saved preference.

Stations

  • Tap or click a station to open its details.
  • On desktop, hover over stations from zoom 7 to preview their details.
  • Station popups include total rain, last reading and recent rain history when available.

Right controls

  • The settings button opens filters, language, preferred period, saved view and terrain options.
  • The 2D/3D button toggles terrain without saving the preference.
  • The layer button switches quickly between Satellite+, Hybrid, Topographic and Liberty.
  • The compass button returns the map to north.
  • The info button shows map, elevation and data credits.

Filters and saved settings

  • Min rain hides stations below the selected accumulated rain.
  • Source filters show or hide Meteocat, Meteoclimatic, Wunderground, AEMET and unknown stations.
  • Last rains history controls how many recent records are shown in popups.
  • Settings are saved for this device only when you close Settings after changing a setting.
  • Use Set current view as default in Settings to choose the initial map position for this device.

Terrain and altitude

  • Long-press the map to query terrain altitude and the nearest rainy station for the current period.
  • Terrain and altitude use an external DEM service, so they can be unavailable if that service fails.

Data notes

  • Source badges show whether each data source is OK, stale, disabled, pending or unavailable.
  • Invalid counts in the header mean some loaded stations were ignored because their coordinates are not usable.
  • This protected viewer uses your Rainmapper login and device registration.
